# pg-coinpush

**推幣機**：投下代幣、推板來回推動、從前方邊緣掉落得分。純前端，無建置步驟。

名稱與盤面為原創小品，致敬「推幣機」玩法類型，非任一商業機台復刻；**純娛樂計分**，代幣與分數無關真實金錢或賭博。

也可當作 [Playgrounds（遊樂場）](https://play.samkuo.me/) 的 **SAM**（`index.html` 入口）。手感想再調？開進來玩，再叫 AI 幫你改一版。

## 操作

| 操作 | 說明 |
| --- | --- |
| 開台 | 開始一局（20 枚代幣） |
| **+20 幣** | 無限續幣（娛樂點數，可反覆加） |
| 點擊／觸控機台 | 在該 X 位置投下代幣（耗 1 枚） |
| 音效開／關 | 靜音 |
| 重來 | 分數與代幣重置、重新鋪幣 |

代幣用盡可點「+20 幣」無限續投，或「重來／再開一局」。

## 規則摘要

- 開台即是一台**已上滿幣**的機台：幣床六方緊密排列、彼此接觸，推板才推得動
- 推板緩慢來回振盪，把整床幣往前擠；推板退回時**不會**把幣帶回來
- 前緣分成**中央得分口**與**兩側邊溝**：只有從得分口掉下的幣得 10 分，滑進邊溝的幣**不計分**
- 落點會影響結果——瞄中央划算，往兩側投容易白丟（這就是機台的莊家優勢）
- 幣心越過前緣才會翻落；半懸在邊上、重心還在檯面的幣會留著

## 物理

刻意保持「不送分」：幣**只會**被推板或其他幣推動。

- 檯面是平的，沒有任何往前的隱形拉力；幣停下後就真的停住（庫倫摩擦，μ≈0.34）
- 推板是剛體，最多只能把幣加速到**推板本身的速度**，不會放大
- 幣與幣碰撞等質量對稱處理：位移各退一半、衝量動量守恆，不偏袒前方的幣
- 接觸求解由後往前逐次掃描（Gauss-Seidel），滿床時推力才能沿整條接觸鏈傳到前緣
- 沒有「清塞」之類的外力補償；代幣停投後幣床會收斂到靜止
- 守恆：投入的幣 = 留在檯面 + 得分口推出 + 邊溝漏掉

以上不變量都有測試把關（`npx vitest run`）。
